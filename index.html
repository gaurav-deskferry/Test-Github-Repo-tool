The crew

Not one agent doing everything. A crew that checks each other.

Lead agent

Plans the task, splits it into parts, asks one question if it must.

Designer

Draws a mockup you can approve before any code.

Implementers

Build the parts in sandboxes, side by side.

Reviewer

Reads the joined change with fresh eyes.

Docs agent

Brings READMEs up to date after a release.

Learning

Turns outcomes into repo memory notes.

Safety manifest

Built like it will be boarded by strangers.

01 A separate agent user

The agent's shell and browser can't read your team's login.

02 An egress allow-list

Outbound traffic only to code hosts, package registries, the model and the app.

03 Secrets in a vault

Encrypted at rest, scrubbed from every log.

04 Never merges

Short-lived, repo-scoped tokens. Your default branch is never touched.
